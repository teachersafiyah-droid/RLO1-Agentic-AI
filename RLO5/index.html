من الفكرة إلى التنفيذ:
كيف تبنين وكيلك الذكي؟

رحلة تطبيقية لتعلّم خطوات بناء وكيل مهني باستخدام Claude Code، من التخطيط إلى التنفيذ والاختبار.

قصة الوحدة

نورة تريد وكيلًا لمهمة مهنية

بعد أن استخدمت نورة الوكلاء في المواءمة الوظيفية والتدريب على المقابلات، تساءلت: كيف أضع خطوات عمل وكيل ينفذ مهمة محددة باستخدام الأدوات المناسبة؟

ناتج التعلم

ماذا ستتعلمين؟

أن ترتبي مراحل إعداد وكيل مهني باستخدام Claude Code ترتيبًا صحيحًا، من تعريف المهمة والبيئة والأدوات إلى الاختبار والمراجعة.

تنبيه: هذه وحدة تجريبية مستقلة. تطبيق خطوات البناء بنفسك اختياري، وقد تتطلب بعض طرق تشغيل Claude Code اشتراكًا أو رسوم استخدام.
02
أتهيأ

ماذا لو كان لديكِ وكيلك الخاص؟

لا نعيد تعريف الوكيل؛ بل ننتقل إلى التفكير في تصميمه.

الموقف المهني

نورة وتكرار تحليل الإعلانات

كلما وجدت نورة إعلانًا لوظيفة تصميم تعليمي، قارنت متطلباته بملفها المهني وكتبت قائمة بالفجوات. تريد الآن بناء وكيل يقرأ ملفًا وإعلانًا افتراضيين ويعد تقرير مقارنة، مع مراجعتها النهائية.

سؤال استكشافي: ما أول قرار تتخذينه قبل فتح أداة البناء؟

03
ألاحظ وأتساءل

وكلاء متعددون… وقدرات مختلفة

تختلف أدوات الوكلاء من حيث التكلفة، والمهارات المطلوبة، والصلاحيات، وطريقة التشغيل.

التكلفة

مجاني أم مدفوع؟

توجد أدوات مجانية، وأخرى باشتراك أو بدفع حسب الاستخدام؛ وقد تتغير الحدود والأسعار.

البناء

دون برمجة أم برمجية؟

بعض الأدوات تقدم محررًا مرئيًا، وأخرى تتطلب إعداد بيئة عمل وأوامر أو خبرة تقنية.

التنفيذ

ما قدرات الوكيل؟

قد يقتصر على التحليل، أو يستطيع قراءة ملفات واستخدام أدوات وتنفيذ خطوات ضمن صلاحيات محددة.

سؤال للمقارنة

خريجة لا تمتلك مهارات برمجية وتريد تجربة سريعة منخفضة التكلفة. ما العاملان الأكثر أهمية في الاختيار؟

سنستخدم Claude Code في عرض البناء؛ وهو خيار تقني ذو قدرات وكيلية، وليس بالضرورة الأسهل أو المجاني لجميع المتعلّمات.
04
أتعلم

Claude Code: أداة بناء وتشغيل

نحدد ما الذي ستفعله الأداة، وما الذي يحتاج إلى مراجعة بشرية.

ماذا يستطيع فعلًا؟

Claude Code أداة وكيلية للمهام البرمجية تستطيع العمل على الملفات واستخدام أدوات التنفيذ المتاحة في بيئة العمل، ضمن إعدادات الصلاحيات.

ما الذي لا نفترضه؟

لا نفترض وجود اتصال تلقائي بمواقع الوظائف أو السماح بتنفيذ أي إجراء دون تهيئة الأدوات والاتصالات والموافقات اللازمة.

قبل التجربة

  • مراجعة دليل Claude Code الرسمي لتحديد طريقة التثبيت والتسجيل المناسبة.
  • استخدام ملفات مهنية وإعلانات افتراضية فقط.
  • تشغيل الوكيل في مجلد تجريبي محدود وعدم منحه صلاحيات واسعة بلا حاجة.
  • مراجعة تكاليف الاشتراك أو API حسب طريقة التشغيل؛ لا ندّعي أن كل المزايا مجانية.
05
أخطط

بطاقة تصميم وكيل مهني

نبدأ بتصميم المهمة قبل الانتقال إلى الأداة.

مثال: وكيل تحليل فجوة المهارات

الهدف

مقارنة مهارات خريجة تصميم التعليم بمتطلبات وظيفة محددة.

المدخلات

ملف مهني افتراضي وإعلان وظيفة افتراضي.

الأدوات

قراءة ملفات من مجلد تجريبي وإنتاج تقرير نصي؛ دون تصفح خارجي في النسخة الأساسية.

المخرجات

جدول توافق، فجوات مهارات، خطوات تطوير مقترحة، وحدود التقرير.

حدود الاستخدام: لا إرسال طلبات توظيف، ولا مشاركة بيانات شخصية، ولا اعتبار التقرير قرارًا نهائيًا دون تحقق بشري.

06
أشاهد وأتعلم

من التخطيط إلى وكيل يعمل

الشرح العملي سيعتمد تسجيل شاشة حقيقيًا للخطوات، وليس لقطات اصطناعية.

مكان فيديو الشرح العملي — لم يُرفع بعد

بعد تسجيل شرح إعداد Claude Code، وتجهيز المشروع، وصياغة المهمة، وتشغيل الاختبار، ومراجعة المخرجات، نضيف الفيديو هنا. لا يوجد مقطع حقيقي مرتبط بهذا المشغل الآن.

خطوات الشرح المقترحة في التسجيل

  1. إعداد بيئة Claude Code
    اتباع خطوات التثبيت والتسجيل في الدليل الرسمي بحسب نظام التشغيل والاشتراك.
  2. إنشاء مجلد عمل تجريبي
    ملف مهني افتراضي + إعلان وظيفة افتراضي، دون بيانات حقيقية.
  3. كتابة مهمة واضحة
    الهدف والمدخلات والمخرجات والصلاحيات المطلوبة.
  4. تشغيل المهمة وملاحظة الأداة
    مراجعة طلبات الصلاحيات قبل الموافقة ورفض الأوامر غير اللازمة.
  5. اختبار التقرير وتحسينه
    التحقق من الأدلة والثغرات، ثم تعديل التعليمات إن لزم.

Do not browse the web, modify other files, send data externally, or submit job applications. Ask for permission before any action beyond reading the two practice files and writing the report.

أفحص

هل تقرير الوكيل موثوق؟

قد يعطي الوكيل تقريرًا مرتبًا، لكنه يحتاج مراجعة الأدلة ومحدودية الاستنتاج.

تقرير تجريبي افتراضي — ليس ناتج تشغيل حي

المهمة: مقارنة المهارات بإعلان مصمم تعليمي

إعلان الوظيفة: يشترط Storyline، وتحليل احتياجات، وقياس أثر التدريب.

الملف المهني: يثبت خبرة في Storyline وتحليل احتياجات، ولا يتضمن دليلًا على خبرة قياس الأثر.

التقويم الختامي

اختبري فهمك لخطوات البناء

اختاري الإجابة الأصح في موقفين عمليين.

1. أثناء الاختبار طلب الوكيل الاتصال بخدمة خارجية غير مطلوبة للمهمة. ماذا تفعلين؟

2. أنتج الوكيل تقريرًا يخلو من أدلة واضحة لبعض المهارات. ما الخطوة التالية؟

10
الخاتمة

من الفكرة إلى التنفيذ المسؤول

اكتشفتِ كيف تخططين لإنشاء وكيل، ومتى تطلبين منه التنفيذ، وكيف تتحققين من مخرجاته.

خريطة تذكّر سريعة

أحدد المهمة ← أحدد المدخلات والصلاحيات ← أجهز بيئة Claude Code ← أنفذ الاختبار ← أراجع النتائج وأحسنها.

بناء الوكيل عمليًا نشاط اختياري. تقيس هذه الوحدة فهم خطوات البناء واختيار الإجراءات المناسبة، ولا تشترط تثبيت أداة أو دفع اشتراك.

إثراء اختياري

إذا رغبتِ في تنفيذ التجربة، اقرئي الدليل الرسمي المحدّث أولًا.
