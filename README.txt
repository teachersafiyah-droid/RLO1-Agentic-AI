مقدمة مسار وكلاء الذكاء الاصطناعي لدعم الجاهزية المهنية
======================================================

التشغيل:
1. افتحي index.html في المتصفح.
2. الشاشات: لماذا الوكيل الذكي؟، وصف المقرر، نواتج تعلم المقرر، إرشادات الاستخدام.
3. عند اكتمال إرشادات الاستخدام وتأكيد الاطلاع، يظهر رابط الوحدة الأولى.

مهم — الفيديو:
لم يُقدَّم فيديو «لماذا الوكيل الذكي؟» ضمن الملفات المرفقة بهذا الطلب.
ضعي ملف الفيديو الحقيقي في assets/why-agent.mp4 ليظهر تلقائيًا في مشغل HTML5.
لا تستبدليه بالمقطع التجريبي للوحدة الأولى؛ فهما مختلفان.

تقدم المقدمة:
يُحفظ محليًا في المتصفح. يتطلب إكمال الشاشة الأولى نهاية تشغيل الفيديو.
الشاشة الثانية: استكشاف محطات الوحدات الأربع.
الشاشة الثالثة: استكشاف نواتج التعلم الأربعة.
الشاشة الرابعة: فتح الإرشادات الثمانية ثم تأكيد الاستعداد.
إذا لم يُدرج الفيديو، لا يُحتسب التمهيد مكتملًا.
المؤشر ليس شهادة إتقان تعليمية.

النشر على GitHub Pages:
- ارفعي محتويات مجلد AI-Career-Learning إلى مستودع، وليس ملف ZIP.
- تأكدي أن index.html في جذر المستودع وأن مجلد RLO1 موجود بجانبه.
- Settings > Pages > Deploy from a branch > main > /(root) > Save.
- رابط المقدمة يكون جذر رابط GitHub Pages، ورابط الوحدة الأولى /RLO1/.
- لا ترفعي ملفات شخصية أو بيانات طالبات، فالمستودع العام ظاهر للآخرين.

التحديث:
عدلي index.html أو styles.css أو app.js ثم ارفعي الملفات المعدلة إلى المستودع.
لإضافة فيديو، ارفعي assets/why-agent.mp4 ثم حدّثي الصفحة.

الوحدات RLO2 وRLO3 وRLO4 والاستبانة لم تُنشأ بعد، ولا تُعرض كرابط عامل.
الوحدة الأولى RLO1 منقولة كما هي من ملف ZIP السابق دون تعديل المحتوى.
الخط العربي يتطلب الإنترنت؛ يوجد خط احتياطي محلي في نظام التشغيل.
