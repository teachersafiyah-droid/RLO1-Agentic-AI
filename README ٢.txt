RLO1 | وكلاء الذكاء الاصطناعي: المفهوم وآلية العمل والتطبيقات
============================================================

الملفات:
- index.html        صفحة الوحدة التفاعلية (ثماني شاشات)
- styles.css        التصميم المتجاوب والواجهة RTL
- app.js            جميع التفاعلات والتقويم وحفظ التقدم محليًا
- assets/           الصور والمقطع التجريبي المضغوط
- docs/storyboard.html  سيناريو ولوحة مشاهد فيديو الدقيقتين
- docs/QA_REPORT.txt  سجل ما تم التحقق منه وما بقي للاختبار

التشغيل المحلي على Mac أو Windows:
1. فك ضغط الحزمة دون تفريق الملفات.
2. افتح index.html من المجلد نفسه بالنقر المزدوج.
3. إذا منع المتصفح بعض الوظائف عند التشغيل بنظام file://، استخدم خادمًا محليًا:
   افتح Terminal داخل مجلد RLO1-Agentic-AI واكتب:
      python3 -m http.server 8000
   ثم افتح http://localhost:8000
4. لا يتطلب المشروع تثبيت مكتبات JavaScript أو حسابات مدفوعة.

النشر عبر GitHub Pages:
1. أنشئ مستودعًا جديدًا.
2. ارفع محتويات مجلد RLO1-Agentic-AI (وليس ملف HTML منفردًا).
3. افتح Settings > Pages ثم اختر Deploy from a branch > main / (root).
4. احفظ وانتظر ظهور رابط الموقع. لا تضع بيانات شخصية في المستودع العام.

حالة الفيديو:
- المقطع الحالي: preview-journey.mp4 وهو مقتطف تجريبي سابق مدته نحو 27 ثانية.
- فيديو الدقيقتين المطلوب غير منتج بعد، ولا يتم تقديمه على أنه مكتمل.
- السيناريو ولوحة المشاهد موجودان في docs/storyboard.html.
- عند إنجاز نسخة نهائية استبدل الفيديو في assets/ وعدّل وسم <source> في شاشة 2 بملفها الصحيح.

التقدم:
- يحتفظ المتصفح بالتقدم محليًا باستخدام localStorage إن كانت سياسة المتصفح تسمح.
- عرض الشاشة أو زيارتها لا يرفع نسبة الإنجاز.
- زر «إعادة ضبط التقدم» يحذف بيانات التقدم المحلية بعد التأكيد.

تنبيه علمي:
تطبيقات الوكلاء والوظائف المستخدمة أمثلة تعليمية افتراضية، وليست عملية بحث وظيفي حقيقية.
النشاطان الكتابيان يراجعان ذاتيًا/بشريًا، ولا يدعي البرنامج تقييم جودة الحجة من النص آليًا.
